# Anti-Slop Audit 001 (2026-09-24)

## Numbered Findings List

### [1] R-32 Keyboard Accessibility & Visible Focus States
* **Priority:** HIGH (Hard Gate)
* **Location:** `cs2-web-radar/src/App.css` (line 97), `CS2/AdminPanel.html` (line 176)
* **Violation:** Inputs use `outline: none` without a distinct custom `:focus-visible` ring, and buttons (`.connect-btn`, `.disconnect-btn`, `.btn-primary`, `.action-btn`) have no `:focus-visible` indicator, preventing keyboard-only users from tracking focus.
* **Suggested Fix:** Add high-contrast `:focus-visible` rings (`outline: 2px solid var(--accent); outline-offset: 2px;`) to all interactive elements.

### [2] R-03 Mobile Touch Target Minimums
* **Priority:** HIGH (Hard Gate)
* **Location:** `cs2-web-radar/src/App.css`, `CS2/AdminPanel.html`
* **Violation:** Several buttons (such as `.disconnect-btn`, `.regen-btn`, and table `.action-btn` elements) have heights under 40px, failing the 44px minimum tap target required for mobile and touch devices.
* **Suggested Fix:** Ensure all touch targets meet a minimum of 44px height/width via padding or `min-height: 44px`.

### [3] R-25 Text Color Contrast on Dark Surfaces
* **Priority:** HIGH (Hard Gate)
* **Location:** `cs2-web-radar/src/App.css` (`--text-dim: #94a3b8`), `CS2/AdminPanel.html` (`--text-muted: #94a3b8`)
* **Violation:** Subtitle text and table column headers using `#94a3b8` on background `#0b0f19` / `#0b0e14` yield a contrast ratio of ~4.1:1, slightly below the 4.5:1 WCAG AA minimum for normal text.
* **Suggested Fix:** Lighten secondary muted text token from `#94a3b8` to `#a5b4fc` or `#cbd5e1` to exceed 4.5:1 contrast.

### [4] R-10 Glassmorphism Dose Cap
* **Priority:** MEDIUM (Purpose-Gate)
* **Location:** `cs2-web-radar/src/App.css` (lines 30–37, 151)
* **Violation:** `backdrop-filter: blur(16px)` is applied globally across multiple panel surfaces simultaneously without differentiating hierarchy.
* **Suggested Fix:** Keep blur on the primary floating card and switch secondary wrappers (like the radar header) to clean solid translucent fills.

### [5] R-07 Generic AI Grid Background Pattern
* **Priority:** MEDIUM (Purpose-Gate)
* **Location:** `cs2-web-radar/src/App.css` (lines 201–206)
* **Violation:** The radar viewport background uses a stacked dot-grid and blueprint line overlay pattern that fits the AI template aesthetic.
* **Suggested Fix:** Replace generic blueprint grid with a subtle tactical crosshair / coordinate vignette suited for CS2 radar display.

### [6] C-2 / R-26 Orphaned Admin Panel CSS Cleanup
* **Priority:** LOW (Quality Lock)
* **Location:** `cs2-web-radar/src/App.css` (lines 340–687)
* **Violation:** Over 340 lines of leftover Admin Panel CSS remain in `App.css` after extracting the admin portal to the offline `AdminPanel.html`.
* **Suggested Fix:** Remove the dead CSS rules to reduce bundle size and maintain clean separation of concerns.

### [7] R-15 Specific Action CTA Copywriting
* **Priority:** LOW (Quality Lock)
* **Location:** `cs2-web-radar/src/App.jsx` (line 270)
* **Violation:** Generic CTA label "Connect".
* **Suggested Fix:** Replace with explicit action copy: "Connect to Live Radar".
